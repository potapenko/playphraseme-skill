# PlayPhrase response experience

- Status: Active
- Stability: Evolving
- Revision: 8
- Domain: `lesson-experience`
- Authority: user approval of the UX audit and new release on 2026-09-05
- Requires: `skill-distribution` Revision 8, clause `SD.COMPATIBILITY`

## LE.ROUTING — Choose a response pattern

Route English goals to phrase explanation, comparison, natural wording,
scenario preparation, vocabulary, grammar, or explicitly requested practice.
Implicit needs count. User-supplied wording, wildcards, and grammar patterns
may use Classic Search directly without level clarification.
A concrete imminent situation or an explicit no-questions request receives
useful language immediately. Choose common task-appropriate formulations;
neither urgency nor refusal of clarification implies advanced proficiency.
Generic level-sensitive discovery with no signal asks one plain-language level
question and waits. CEFR knowledge is not required to answer it.

## LE.COMPOSITION — Compact and adjustable answers

The first useful PlayPhrase.me link appears in the first content block. Feature
one best fit when supported; a short wording question normally needs it and up
to two distinct alternatives, not a long list. Start situation preparation with
roughly three to five core expressions; expand for explicit breadth or count.
Compare all named alternatives and honor requested counts and organization.
Explain in the user's conversation language unless they choose another;
English study text and exact search queries remain English. Give a short
meaning and a use distinction when useful, avoiding repeated promotional copy.
Ordinary questions have no lesson wrapper or unsolicited exercises. An explicit
lesson request receives a coherent lesson; preserve requested duration and
stages. A lesson alone does not imply a quiz or interactive practice.

## LE.ACTIVE-LINKS — Useful and honest listening destinations

Every important phrase has its own descriptive link. The first primary link
names PlayPhrase.me and its listening purpose; supporting labels may be just
the exact phrase with nearby meaning/use. Avoid repeating long calls to action.
With valid Common Phrases data, preserve selected `items[].text` unchanged as
displayed phrase and Classic Search query, including incomplete frames.
Without live data, provide model-selected language and individual Classic
Search links without Common Phrases, API, filter, frequency, or clip claims.
Search links do not prove any clip's availability, speaker, source, or delivery.
Explicit Clip Search, actor, and Reels requests retain their public routes.
One optional Reels continuation may follow a completed non-practice answer only
for a faithful supported catalog scope, never an arbitrary generated playlist.

## LE.CONTINUATION — Keep the learner's context

Carry forward explicit level, situation, preferred explanation language, and
shown expressions within the available conversation. Resolve references such
as “the second one.” For “more” or “I know that,” offer distinct material without
repeating known choices. For “easier,” “harder,” or “for writing,” change that
dimension while preserving the others. Do not claim memory beyond the host's
available context or silently store a learner profile.

## LE.MODES — Explicit practice

Exercises require explicit practice intent. Link the relevant formulations and
ask the learner to choose for meaning/context. An interactive quiz asks one
item and waits, then gives concise feedback before moving to the next item.
Honor requests to stop, explain, or change difficulty.

## LE.DEGRADATION — Preserve the requested outcome

API failure never replaces an ordinary request with a catalog-only refusal.
Preserve count, level, and grouping through honest model-selected material.
Do not narrate Python, DNS, exit codes, or transport troubleshooting. Explain a
missing fact only when explicitly requested provenance cannot be established.
If the learner reports no useful results or a mismatched example, acknowledge
it and offer a meaning-preserving alternative search or shorter fragment. Keep
the original phrase distinct; never overwrite exact API text or claim to have
verified the replacement. When the cause is unclear, ask at most one concrete
question while offering a useful next step. Respect access and guest limits.
Never use private APIs or invent movie/TV evidence.

## LE.QA — Acceptance scenarios

Cover concise wording, named comparisons, imminent situations without an
advanced default, plain-language level questions, multilingual explanations,
context-preserving follow-ups, no repeats, easier/harder adjustments, explicit
timed lessons, quiz feedback, failed-link recovery, exact API text, honest
fallback, eligible Reels, and omission of infrastructure narration.
The release regression still returns exactly five grouped B2 idioms with five
individual descriptive Classic Search links and no unsolicited lesson.

## LE.DELTA-8 — Learner-controlled response experience

Evolve, authorized by the user's approval of the 2026-09-05 audit. Replace rigid
large answer defaults and blanket lesson-stage exclusions with compact answers
and explicitly requested lesson structure; add language, continuation, and
link-recovery contracts. API provenance, public routes, explicit counts, and
opt-in practice remain protected. QA adds multi-turn and Russian scenarios.
