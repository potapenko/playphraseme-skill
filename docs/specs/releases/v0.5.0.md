## Compatibility

The release routes ordinary ChatGPT Web/Work candidate requests through a
network-neutral URL handoff instead of Python networking, while Codex and other
code hosts retain the normal client. It also answers imminent unknown-level
situations with a disclosed B2–C1 working range. Common Phrases provenance,
exact returned text, canonical public URLs, request limits, `429` stopping,
direct user searches, public-link degradation, ZIP installation, and supported
prompt-based installation remain protected.
