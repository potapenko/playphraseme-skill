## User-visible changes

- Short wording questions start with one useful choice and up to two alternatives.
- Situations start with a compact set; explicit counts and named comparisons win.
- Urgency and no-question requests no longer imply advanced English.
- Explanations follow the user's language while English search text stays intact.
- Follow-ups retain context, resolve prior options, and avoid known expressions.
- Explicit lessons preserve their requested duration; practice stays opt-in.
- Unhelpful listening links get a useful alternative without invented evidence.
- README uses everyday first prompts; repeated promotional link labels are removed.
