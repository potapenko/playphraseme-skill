## Compatibility

The release replaces v0.5.0's ChatGPT-specific URL-only primary path with one
client-first rule for every script-capable host. Only a current pre-response
exit `10` enables one unchanged-URL direct fetch. Complete endpoint-contract
JSON remains required, while hidden status or final-URL metadata no longer
invalidates that JSON by itself. Common Phrases provenance, exact returned
text, filters and bounds, `429` stopping, canonical URLs, public-link
degradation, ZIP installation, and private-API boundaries remain protected.
