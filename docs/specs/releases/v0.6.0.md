## Compatibility

The release removes bundled Python clients and URL builders. The skill now
describes one instruction-only workflow that works in ChatGPT and coding hosts:
use the public Learning API as optional bounded enrichment when available, and
otherwise complete the requested phrase path from model knowledge without
claiming PlayPhrase.me catalog provenance. Live Common Phrase text remains
exact; filter semantics, level routing, tracking-free public URLs, useful
degradation, and private-API boundaries remain protected.
