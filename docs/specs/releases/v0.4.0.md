## Compatibility

The release adds level-first open-ended discovery, Common Phrase-backed
agent-selected examples, exact returned phrase text, and a bounded matching
Reels continuation. Direct user searches, canonical public URLs, API limits,
evidence boundaries, ChatGPT ZIP installation, and prompt-based installation
for other compatible hosts remain supported.
