# Project instructions

## ChatGPT installation and acceptance

Install, update, and verify this project's ChatGPT skill only in Safari through
Computer Use. Safari is the operator's authenticated ChatGPT account.

Do not use Chrome, dev-browser, CDP, or Playwright for ChatGPT installation or
release acceptance. A signed-out Chrome session is not a blocker and is not a
reason to ask the operator to sign in there.

Before operating Safari, follow the global `computer-use-governance.md` route
and the installed Computer Use skill. If Computer Use is unavailable, report
that specific limitation; do not substitute another browser or account.

This is the operator's local release workflow, not a browser restriction for
users of the published skill. Keep this rule out of the distributable package.
